# 設計

## 概要

Visual Pitch Trainer は、難聴者向けに音程練習を視覚的に支援するWebアプリである。

利用者は参考音（ド・レ・ミなど）を再生し、その音に合わせて発声する。アプリはマイク入力をリアルタイムに解析し、目標音との差や時間経過による音程の上下を画面上に表示する。

音を聞いて判断することを前提にせず、視覚的なフィードバックを中心に設計する。

表示フォントには Google Fonts の利用を許容する。また、ボーカル抽出や RMVPE / CREPE 推定を有効にした場合は、ブラウザ内で使う ONNX Runtime Web の WASM ファイルやモデルを取得するための外部通信を許容する。音源解析用のピッチ推定モデルは公開成果物に含める。音声データ、マイク入力、解析結果を外部へ送信する設計とは切り分けて扱う。

## 主な要件

- 難聴者向けの音程練習ができること
- 参考音を再生しながら発声練習できること
- 発声した音程をリアルタイムに分析できること
- 目標音とのズレを視覚的に把握できること
- 時間経過による音程の上下が見えること
- PC、タブレット、スマートフォンで動作すること
- サーバなし、静的ホスティングのみで動作すること

## 体験設計

中心となる体験は、以下の流れとする。

1. 利用者が目標音を選ぶ
2. アプリが参考音を再生する
3. 利用者が参考音に合わせて発声する
4. アプリがマイク入力から音程を検出する
5. 目標音との差や高低の傾向を表示する
6. 発声中の音程変化をリアルタイムグラフで表示する

この体験により、利用者は「今の音が高いか低いか」だけでなく、「発声中に音程が上がっているか、下がっているか、揺れているか、安定しているか」を視覚的に確認できる。

## 主要画面

スマートフォンの狭い画面では、単音練習・メロディ練習・自分の声域チェックの実行中に停止操作を画面下部に置く。メロディは準備中とカウントダウン中も停止できる。声域チェックの記録消去は結果付近に置く。

上部メニューで単音練習・メロディ練習・ゲーム・自分の声域チェック・音源の声域確認を切り替える。音域・音色・音量・マイク・判定幅はタブから独立した「共通設定」としてメニューの上に置く。単音・メロディ・ゲームに適用されることを明記し、「共通設定を開く」ボタンでモーダルの設定画面を表示し、練習画面には現在の音域・音色・音量・判定幅を常に表示する。初期音色はピアノとする。メロディと1音の長さは「メロディ設定を開く」ボタンから同様の設定画面で変更し、選択中のメロディと長さは練習画面に残す。変更は即時反映し、「閉じる」ボタン・Escapeキー・背景のクリックで閉じ、開いたボタンへフォーカスを戻す。単音の目標音は練習画面で選ぶ。共通設定は音源の声域確認には適用しない。切り替え時はマイクと参考音を停止し、音源再生を一時停止する。単音の練習記録、メロディの振り返り、音源の解析結果は保持する。

### 自分の声域チェック

マイクで出せた声の最低音・最高音を確認する独立した画面を設ける。同じ音を一定時間保てたときに記録し、単発の検出ミスを範囲に含めにくくする。目標音による候補選択やオクターブ補正はせず、ドレミ＋オクターブ、国際式、カラオケ式の3表記を併記する。カラオケ式はAを境界とし、LowG＝G2、mid1G＝G3、mid2C＝C4、hiA＝A4とする。地声・裏声や声種は判別しない。最低音と最高音の間がすべて歌えるという診断にはしない。

入力の状態・保持時間・記録した各音を文字と進捗で示す。時間に沿った声の高さを直近12秒のグラフに表示し、記録した最低音・最高音を破線と文字で示す。縦軸は検出音と記録した範囲に合わせ、目盛りの表記は3方式から選べる。無音・検出不能・停止区間を線で結ばず、停止後は表示を保持する。停止、再開、全記録の消去を提供する。停止後は誤記録した音を個別削除でき、最低音・最高音とその破線も更新する。検出した声の軌跡は残す。画面を切り替えた場合や非表示になった場合はマイクを解放する。結果はページ内にだけ保持し、音声や記録を送信しない。

### PWA

ホーム画面への追加と基本画面のオフライン起動に対応する。静的アプリ構成を維持し、大容量モデルや外部WASMを自動取得しない。音源素材は使ったものを保存する。更新による練習中の再読み込みを避け、開いているアプリをすべて終了した後に新しい版へ切り替える。

### 練習画面

現在の中心画面。

表示する情報:

- 目標音
- 音域選択（C3-C4: 低めの男性声 / C4-C5: 高めの男性声・低めの女性声 / C5-C6: 高めの女性声）
- 参考音再生ボタン
- 参考音量
- お手本の音色（正弦波 / ピアノ）
- マイク開始・停止
- 目標音との音程差
- 高い・低い・合っている状態
- リアルタイムピッチグラフ

操作:

- 声の高さの目安つきで C3-C4 / C4-C5 / C5-C6 の音域を選ぶ
- 半音を含む1オクターブ分の目標音から選ぶ
- 参考音を再生する
- 参考音量を調整する
- マイク入力を開始する
- 練習を開始・終了する

### メロディ稽古（試作）

最初の練習は2トーンスケール（ド・レ）とし、3トーン（ド・レ・ミ・レ）と5トーン（ド・レ・ミ・ファ・ソ・ファ・ミ・レ）も用意する。折り返しの音は1回鳴らし、次の周の頭で開始音に戻る。音型を選ぶとドから始まり、練習画面で開始音を音階上で1つずつ上下できる。練習中は開始音の手動変更とランダムの「次の音型」を使える。発声中の変更は次の周の頭、カウントダウン中の変更は最初の周に反映する。切り替わる周と予約した音型や開始音を表示し、終わった区間の結果も残す。ランダムは初期状態ではオフとし、有効にするとドに戻る。「次の音型」を押すと、隣り合う音の間隔や上がり下がりが直前と異なる音型を選ぶ。各移動は音階上で上下1・2・3音までの選択した幅に収め、往路には指定音数の異なる音を使う。音型全体を共通設定の音域に収め、発声前にグラフと音名で確認できるようにする。

専用グラフで全メロディのお手本を初めから表示する。縦軸は全目標音を含む固定音域、横軸は1周分の固定時間軸とする。トーンスケールは共通設定の音域を基準にし、開始音を変えても同じ音の高さを保つ。お手本は横棒と許容幅の帯、声は別色の線、現在位置は縦の破線で区別する。お手本のバーは残し、声の履歴は周回ごとに描き直す。停止後は停止した周回を振り返れるようにする。単音用の直近12秒グラフとは分ける。長いメロディはスクロールし、発声中は位置を追い、終了後は自由に確認できる。音名一覧も文字で提供する。

メロディ稽古は試作として、長音階上行・下行、ドミソミド、半音階、自由メロディ（選択音域内の2〜32音、同じ長さ、休符なし）を扱う。マイクの利用許可と音色の準備後、最初に3秒のカウントダウンを行い、お手本と一緒に発声・判定を始める。停止するまでメロディを繰り返し、周回の間には待ち時間もカウントダウンも入れない。1音の長さはお手本と発声に共通で適用し、0.5秒と1〜5秒（既定2秒）とする。カウントダウンはグラフ上の大きな数字と進捗バーで示す。合図音は3・2・1と開始を同じAudioContextの時計で予約し、オン・オフ可能とする。現在の音・残り時間・進捗とグラフの目標音を連動させる。各周回の最初の0.4秒を除き、停止後に全周回の音ごとの合った時間・割合・検出時間を示す。割合の分母は停止までの実際の判定対象時間とし、無音と途中の周回も含める。判定対象時間のない音は「—」と表示する。ヘッドホン利用を案内し、回り込みと声を区別した採点とは扱わない。実際の練習効果は未検証とする。

隣接する目標音の差は、移動先のバー付近に図形アイコン付きのバッジを置き、バー同士をつなぐ線でも示す。文字の矢印の代わりに、音のバーと上昇・下降・水平の軌道を組み合わせたベクターアイコンを使い、グラフ直上のNEXT欄でも揃える。半音、全音、オクターブ、同じ高さを表記し、それ以外は「半音4個分」のように半音数を示す。全音には半音2個分も補足する。バッジには「上げる」「下げる」を添え、専門的な度数名の知識を前提にしない。次に向かうバッジは金色と太枠、再生中のバーは太線と進捗で強調する。バーの案内は点滅や揺れを使わない。音名一覧と読み上げ用テキストにも方向を言葉で説明する。カウントダウンでは発声パートの最初の音へ戻し、練習中の最終音ではNEXT欄と鍵盤で先頭への移動を案内する。

バーの直下に、実際のピアノと同じA0〜C8の88鍵を低めの高さで置く。白鍵の幅を保って横スクロールでき、現在と次の鍵盤が範囲外になったときと画面幅変更・再表示時に両方が見える位置へ移動する。丸・ひし形や「今／次」の文字を鍵盤に重ねず、現在／次の音名は鍵盤の左下に表示する。現在の鍵盤は音の切替直後を強い色から始める1.4秒周期の明滅と内側の発光で強調する。緑の囲み枠は使わず、現在の鍵盤の列に合わせて鍵盤の上下に細い光を出し、お手本の切替時に小さな火花を散らす。鍵盤領域の高さを増やさず、音名行にかからない範囲に収める。次の鍵盤は淡い色と点線枠で控えめにする。音名は静止させ、「動きを減らす」設定では明滅と周囲のエフェクトを止める。色だけに依存せず、現在と次の音名・オクターブも文字で示す。同音反復では同じ鍵盤に発光・明滅と点線枠を併記し、練習中の最後の音では先頭を次の鍵盤として強調する。最後の音で停止した場合は次の強調を消す。プレビューと待機中は先頭とその次を示す。見出し・凡例・説明文は置かず、現在／次の音名と鍵盤だけに絞って高さを抑える。鍵盤はお手本の位置を示す表示とし、新たな演奏操作やマイクの検出表示は加えない。音の感覚と位置の対応を掴む助けになるかを試すもので、学習効果は未検証とする。

### 音程ゲーム（試作）

開始前のモード選択はアイコンと短い説明付きのカード、問題数・キープ時間・音当ての難易度は直接押せる選択ボタンで示す。選択中は枠・チェック・モードカードの「選択中」で区別し、色だけに依存しない。操作はネイティブのラジオボタンとし、グループの見出し、キーボード操作、フォーカス表示を保つ。狭い画面ではモードカードを縦に並べる。選択操作だけでは音やマイクを開始せず、ゲーム中は全設定を無効化する。

発声チャレンジと音当てを独立したゲームとして追加する。発声チャレンジは選択音域内のランダムな目標に3秒以内で到達し、そこから指定秒数を連続キープする。最初に3秒の視覚カウントダウンを表示し、出題中の参考音再生は行わない。無音・検出不能や検出間隔の途切れを連続成功に加算しない。目標バー、声の軌跡、音程差、残り時間・進捗を併用する。

音当てはマイクを使わず、選択音域内の音を再生して音名を答える。初級は3半音間隔5択、上級は半音間隔13択。再生中の回答は受け付けず、聴き直し可能とする。回答後は正解を文字と形で示し、利用者が次へ進む。

両ゲームは5問 / 10問で区切り、100点＋連続成功ボーナス、発光・粒・任意の効果音、終了ランクを表示する。動きを減らす設定を尊重し、音や色だけに成功表現を依存させない。設定別の完走自己ベストのみブラウザ内保存し、再挑戦ボタンと結果一覧で継続を支援する。通常の単音スコアには加算しない。

### リズム練習

足で一定の拍を刻み、手で音符に合わせてタップする練習。上段の音符アイコンは手で叩く位置、下段の足あとは足の拍を示す。全音符・2分音符・4分音符・8分音符・16分音符と付点音符を描き分け、見本では記号の名前と拍数も示す。どちらも右から左へ移動する。流れるアイコンの中心を示す点線が固定の判定ラインに重なった瞬間に叩く。1拍目は数字と足あとを大きくし、その拍に音符がある場合は音符も大きくする。タップの位置は判定線より右で早い、左で遅いことを示し、記号と文字でも伝える。練習中は全小節の音符と休符をレーンの上に並べ、音符ごとの位置に判定を表示する。4分休符と8分休符は見本と流れるレーンにも表示する。結果画面でも全小節を振り返れる。スマートフォンではタップ領域を広く取り、リズムの例は折りたためる。動きを抑える設定では足の沈み込みを止め、レーンの進行は維持する。

ステップ選択では、各見本を1小節ずつ再生するか複数の見本を順に通して再生できる。足の拍はバスドラム、手の音符はハイタムで示し、選択した声でカウントを重ねられる。図にも再生位置を示す。8分音符のカウントで使う「&」には、拍と次の拍の中間を示す説明を添える。練習画面を開くと、最初の小節の例が止まった状態で表示される。練習を始めると、音源を読み込む間はスピナーを表示する。読み込み後は無音の円形ゲージで準備までの3秒を示す。そのあと曲と同じテンポで、足で拍を刻む準備の2小節から本番へ進む。第1〜3章の本番は4小節、第4章は曲に応じて8〜12小節。準備の拍はグレーの背景、点線の判定線、輪郭の足あとで示す。レーンに入ってきた本番区間は青系の背景で区別し、その境目も拍と同じ速度で動く。採点は本番の拍を対象とする。ステップ一覧の各項目と練習画面に拍子とテンポを表示する。コースは「ゆっくり基礎」6ステップ、「だんだん速く」6ステップ、「裏拍」4ステップ、「実践編」11ステップ。4/4・3/4・2/4拍子の曲を使い、「月光」は冒頭の三連符、「カルメン〈ハバネラ〉」は16分音符を含む伴奏のリズムを扱う。見本はピアノとバスドラムを通して再生できる。ステップを選ぶと小節ごとの譜例が開く。実践編では「練習画面へ」を譜例の上に置く。本番はピアノとバスドラムを流れる譜面と同期して再生し、メロディーの発音位置をタップする。バスドラムで足の拍を示し、小節の1拍目を強く鳴らす。最初のステップは足とタップが同時になる4拍を例に示し、練習中は下段の拍に合わせたタップを判定する。第1章は「ぴったり」と「ちょっとずれ」の合計が85%以上で合格とする。各ステップを2回連続で合格すると次に進める。ステップ選択と練習結果で必要な残り回数を表示する。設定で全ステップを自由に選べる。判定結果は自由に選んだときも記録する。

補正なしですぐ練習を始められる。設定でBPM 80の光る円またはクリック音に合わせてタップを測定し、いつも同じ方向に生じるタイミングのずれを補正できる。測定前に3秒のカウントダウンを表示する。視覚の補正値は個別に解除できる。判定に使うガイドも設定で選べる。カウント音は音声、クリック、なしから選べ、音量と判定音も調整できる。補正測定のカウントダウンは電子音で知らせる。練習で音声を選ぶと、足を踏む位置を選択した声で知らせる。4/4拍子は1・2・3・4、3/4拍子は1・2・3、2/4拍子は1・2を繰り返す。実践編ではカウント音を準備の2小節で鳴らす。設定の音量はカウントと曲に適用する。進捗、補正、リズム練習の設定はブラウザ内に保存する。判定幅と合格基準は実機と利用者の評価で見直す。

### 設定項目

現在の画面では、練習に必要な設定を同じ画面内で扱う。

- 判定の幅: 半音の何%を許容するか。難聴者・初心者向けの初期値は緩めにする。
- マイク感度
- 音域: C3-C4 / C4-C5 / C5-C6 など。初心者向けに「低めの男性声」などの目安を併記する。
- 参考音量

今後の拡張候補:

- 基準ピッチ A4 = 440Hz / 442Hz など
- 音名表記: ドレミ / CDE
- 色覚特性に配慮したテーマ

### 履歴

現在は練習サマリーを画面上に表示する。履歴保存を追加する場合は、以下を扱う。

- 練習日時
- 練習した目標音
- 平均の音程差
- 安定して発声できた時間
- 音程グラフの簡易振り返り

### 音源の声域推定

ローカルの音源ファイルまたは動画ファイルを読み込み、ブラウザ内で歌声らしい音程の範囲を推定表示する。

伴奏入りの通常楽曲を直接解析すると、ベース、ギター、シンセ、ハモリなどの音程を拾って声域推定やグラフが乱れやすい。そのため、WebGPU 対応ブラウザでは Demucs 系モデルや RoFormer 系モデルによるボーカル抽出を任意で行い、抽出後のボーカル音声を声域推定に渡す。さらに、WebGPU 対応ブラウザでは CREPE や RMVPE の ONNX モデルによるニューラルピッチ推定を任意で比較できるようにする。WebGPU 非対応環境や処理が重すぎる端末では、抽出済みボーカル音源を読み込ませるか、従来の軽量なピッチ検出を使う運用も許容する。

表示する情報:

- 推定声域
- よく出る範囲
- 中心付近の音
- 検出できた歌声らしい区間の割合
- 時間経過に沿った推定ピッチの点群と中心線
- 音源再生中の現在位置を示す縦線
- ボーカル抽出を行った場合の抽出ボーカルMP3保存

将来的な拡張候補:

## 視覚フィードバック

難聴者向けであるため、音の状態を色だけに依存して表現しない。色、位置、形、数値、文言を組み合わせる。

Canvas のグラフは主要な視覚表現だが、状態文、数値、サマリー、必要に応じた補助テキストで内容を補う。

### 現在音程メーター

現在は採用せず、リアルタイムピッチグラフを主役にしている。将来的に復活させる場合は、目標音を中央に置き、現在の音程が高ければ上、低ければ下に表示する。

- 中央: 目標音
- 上方向: 目標より高い
- 下方向: 目標より低い
- 中央付近: 許容範囲内

### リアルタイムピッチグラフ

横軸を時間、縦軸を音程とする。

- 目標音を水平線で表示
- 発声した音程を線で描画
- 無音や検出不能区間は線を途切れさせる
- 許容範囲を帯で表示する
- 目標音に近づくほど目標ラインを発光させる
- 許容範囲に入った瞬間は波紋で着地を示す

このグラフにより、音程の上ずり、下がり、揺れ、安定度が見える。

### 状態表示

状態は短い文言と形で示す。

- 低い
- 合っている
- 高い
- 音が小さい
- 検出できない
- 連続して合っている時間

## 音声処理

ブラウザ内で Web Audio API を使う。

### 参考音再生

持続する録音音色としてハルモニウム・オルガン・バイオリン・フルートも選べる。録音の安定した持続区間をループ化し、短いフェードイン・アウトで鳴らす。ピアノの繰り返し打鍵とは分けて扱い、メロディ稽古では1音の長さだけ持続する。音程は録音の実測値で補正するが、ビブラートなどの細かな変動は完全には除かない。録音の音域外は再生速度による移調とし、その旨を説明する。録音由来の練習用音色であり楽器を忠実に再現することや、特定音色の練習効果は保証しない。

正弦波は `OscillatorNode`、録音音色は `AudioBufferSourceNode` で再生する。既定はピアノとする。

共通設定の音色選択の横に「試聴」を置く。「きらきら星」の冒頭を約5秒、選んだ音色と音域、お手本音量で鳴らす。再生はボタンを押したときだけ行い、進行中の練習・計測・音源再生を止めてから始める。ボタンでの停止、音色・音域の変更、設定画面を閉じる操作で試聴を止める。

正弦波は継続音、ピアノは自然な減衰を保った約2.5秒間隔の繰り返し打鍵とする。再生中の目標音・声の高さ・音量変更に追従し、メロディ稽古でも選択中の音色を使う。音色変更でメロディを中止した場合とページを閉じた場合は、予約済みの音も停止する。

ピアノ素材は VCSL の CC0-1.0 録音をアプリに同梱する。コードと音源素材のライセンスを区別し、固定した出典・チェックサム・加工内容を記録する。音源は初回再生時のみ同一配信元から取得する。外部 MIDI / SoundFont ライブラリは導入しない。音色の追加は音色定義と素材で扱う。

参考音量は画面上のスライダーで調整できる。スピーカーからの回り込みを抑えたい場合にも使う。

今後の拡張候補:

- 声に近いガイド音
- バイオリン等の楽器音色

### マイク入力

`getUserMedia` でマイク入力を取得する。

利用時の注意:

- HTTPS環境が必要
- ローカル開発では localhost で利用可能
- ユーザー許可が必要
- スマートフォンではブラウザ差異を確認する必要がある

### 音程検出

検討したアルゴリズム:

- YIN
- autocorrelation
- McLeod Pitch Method

手書き実装ではなく、ブラウザ対応の既存ライブラリを使う。マイクのリアルタイム音程検出は、ライセンス面とブラウザでの扱いやすさを考慮し、`pitchy` の McLeod Pitch Method を使う。音源ファイル解析では、軽量な `pitchy` に加えて、WebGPU 対応環境向けに RMVPE / CREPE の ONNX モデルを選べるようにする。精度、遅延、スマートフォンでの処理負荷を見ながら調整する。

### 音程変換

検出した周波数 Hz を以下に変換する。

- MIDI note number
- 音名
- 目標音との音程差

内部計算では cents 差分を使う。画面上では初心者にも分かりやすいように「半音の何%くらいの差か」として表示する。

### 音源ファイル解析

音源ファイル解析は `File API` と `AudioContext.decodeAudioData()` でローカルファイルを読み込む。動画ファイルやブラウザ標準で読み込めない形式では、Mediabunny を使って音声トラックを demux/decode し、PCM データへ変換する。得られた音声はモノラルにミックスしてから短いフレーム単位でピッチ検出する。

ボーカル抽出を有効にした場合は、Demucs 系モデル、RoFormer 系モデルを ONNX Runtime Web / WebGPU で実行し、抽出されたボーカル音声を声域推定へ渡す。抽出ボーカルはブラウザ内で保持し、再生や MP3 保存に使う。RoFormer 系は vocal / instrumental の2 stem特化モデルとして扱い、品質検証用に BS-RoFormer を選べるようにする。音源ファイル解析のピッチ推定では、既定は RMVPE としつつ、通常のPCやスマートフォンなど処理負荷が気になる環境では pitchy、比較検討では CREPE small / medium / large / full も選べるようにする。RMVPE / CREPE は ONNX Runtime Web / WebGPU で実行し、歌声向けのピッチ候補を使う。音声データはサーバへ送信しない。

### 現在の構成

サーバなしの静的Webアプリとして構成する。

```text
Static Hosting
  └─ Browser App
      ├─ Reference Tone Playback
      ├─ Microphone Input
```
